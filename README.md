## Twigonometry:

A library mod to make generating trees in-code a little bit less painful. Lets you draw configurable simple shapes on a layer by layer basis with adjustable randomness, a decay check, custom attachments, utils and more.

## How to use:
To get started check out the [wiki page](https://github.com/maksiksq/twigonometry/wiki/Getting-Started).
